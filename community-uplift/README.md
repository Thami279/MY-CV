# Community Uplift

Single-page static site that showcases volunteer-led programmes designed to boost learning opportunities in rural communities.

- Live site: https://thami279.github.io/community-uplift
- Source repository: https://github.com/Thami279/community-uplift

## Page overview
- Hero and mission statement introducing Community Uplift
- Cards highlighting volunteer networks, resource library, and technology partnerships
- Programme summaries for Future Coders Club, STEM on Wheels, and Health Voices
- Impact statistics and community testimonials
- Contact footer inviting partners and volunteers

- `static_url.txt` — GitHub Pages URL for this deployment

## Local development
Open `index.html` directly in a browser, or run a static server (for example `python -m http.server`) from this folder.
